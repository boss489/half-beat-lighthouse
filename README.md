# 반 박자 등대

한국어 2D 브라우저 항로 게임. 설치·계정·외부 API·유료 라이브러리 없음. `index.html`을 브라우저에서 열거나 이 디렉터리에서 `python3 -m http.server 8799`를 실행한 뒤 `http://127.0.0.1:8799/` 접속. ES 모듈 파일을 직접 여는 경우 브라우저의 `file://` CORS 제한으로 작동하지 않을 수 있으므로 로컬 서버를 권장합니다.

## 규칙

- 9×7 지도. 배는 지도 가장자리의 매 항로마다 다른 출발점에서 지정된 방향으로 출발해 1박자마다 앞칸으로 한 칸 이동합니다. 암초나 지도 밖에 닿으면 실패, 초록 항구에 닿으면 성공. 방패가 있으면 충돌 1회를 막고 배는 제자리에 남습니다.
- 렌즈는 배가 해당 칸에 **진입한 직후** 다음 진행 방향을 결정합니다. ◉ 지시 렌즈: 표시된 ↑→↓← 방향으로 설정. ◇ 반사 렌즈: 설정값의 짝수/홀수에 따라 진행 방향 기준 우회전/좌회전(숫자 0·2는 우회전, 1·3은 좌회전). ✦ 프리즘: 현재 방향에 180° + 설정값 × 90°를 더합니다(0=뒤로, 1=왼쪽, 2=직진, 3=오른쪽).
- 회전은 즉시 일어나지 않고 **예약한 박자 + 2**에 적용됩니다. 전지를 먹고 빠른 예약 횟수가 남아 있으면 다음 회전 예약에 1회를 소비하고 +1박자에 적용됩니다. 같은 박자에 같은 렌즈의 예약이 여러 개면 입력 순서대로 처리되어 마지막 예약이 유효합니다. 선박 이동 전 예약이 먼저 반영됩니다. 출항 전에도 예약 가능. 렌즈 위 ⏱ 표시는 남은 박자, 숫자 점선은 현재 예약을 반영한 향후 최대 6박자의 예측 위치입니다. 점선은 충돌 또는 입항 지점에서 끝납니다.
- 부표는 진입할 때 한 번만 작동합니다. ★ 별은 +30 보너스, ϟ 전지는 빠른 예약 1회, ⬡ 방패는 충돌 방어 1회, ➜ 조류는 해당 항로의 직진 방향으로 배를 정렬합니다(셀 접근성 이름에서 방향 확인). 미리 부표를 눌러 **증폭**하면 각각 +60점 / 빠른 예약 2회 / 방어 2회 / 조류 방향에서 시계방향 90° 전환으로 바뀝니다. 조류의 증폭 방향 바로 앞에는 암초가 있어 증폭은 위험합니다.
- 점수는 입항 시 `max(100, 1000 + 별 보너스 − 소요 박자 × 12 − 방패 충돌 × 35)`. 충돌 실패에는 점수가 없습니다. 스테이지·무한 항해 점수 각각 상위 10개 및 완료한 번호는 해당 브라우저의 localStorage에만 저장됩니다. 온라인 순위가 아닙니다.
- 30개 스테이지: 1–5 한 굴절, 6–12 두 굴절, 13–20 세 굴절, 21–30 네 굴절. 지도 사방의 다른 출발 위치·진행 방향, 다양한 굴절 순서·위치와 항구 위치를 갖는 자기 교차 없는 항로를 생성합니다. 스테이지가 오를수록 암초 밀도·렌즈 종류·예약할 굴절 수가 증가합니다. 잘못된 굴절 방향 일부에 즉시 충돌하는 암초를 배치하고, 조류 증폭 시에는 암초로 향하게 합니다. 모든 스테이지는 예약 입력과 매 박자 이동을 실제 시뮬레이션해 입항을 확인할 수 있습니다. 무한 항해도 숫자 시드마다 4굴절 항로의 방향·위치·암초 배치를 재생성하며 같은 시드는 재현됩니다. 다만 각 지도는 단일 설계 항로와 지정 렌즈의 퍼즐이지 자유 항해 지형/무한한 분기 생성기가 아닙니다. 30개 번호를 자유 선택 가능하며 잠금/시간제한은 없습니다.

## 조작

- 지도에서 렌즈 **클릭/탭**: 해당 렌즈 선택 후 시계방향 예약. **우클릭**: 반시계 예약. 하단 `← 렌즈` / `렌즈 →`로 선택, `↶ 반시계` / `시계 ↷`로 회전. 부표 클릭/탭은 증폭 켜기/끄기.
- 키보드: `←/→` 선택, `A/D` 반시계/시계 예약, `Enter/Space` 출항·일시정지 (다른 버튼에 포커스 중이라면 그 버튼의 기본 동작), `N` 한 박자 진행, `R` 재시작. 지도에서 좌/우 스와이프로 선택된 렌즈 회전 예약. 화면 버튼만으로도 모든 조작 가능.
- `▶ 출항`은 자동 0.9초 박자를 켜고 끕니다. `한 박자 진행`은 자동 재생을 멈추고 1박자 진행. 완료/실패 후 출항 버튼은 같은 항로 재시작. `↺ 다시 시작`은 즉시 초기화.
- 상단 소리는 기본 꺼짐; 버튼으로 Web Audio 효과음을 켤 수 있습니다. 고대비/움직임 줄이기/자동 박자 설정, 키보드 포커스 테두리, 셀의 접근성 이름과 상태 안내 영역 제공. 움직임 줄이기는 OS 설정도 따릅니다.

## 테스트

```sh
node --test game.test.mjs
node --check logic.mjs
node --check app.mjs
```

테스트는 30개 항로의 예약 입력과 매 박자 항해 및 무한 모드 24개 시드의 실제 시뮬레이션을 확인합니다. 경로의 방향 결정·이동 형태·출발·도착·첫 렌즈 위치 다양성과 잘못된 굴절/조류 증폭 암초 위험을 검증합니다. 추가로 무한 시드 500개를 시뮬레이션했습니다. 예약 적용 시점·입력 순서·예상 항로 불변성·세 렌즈·네 부표·충돌 및 방패·시드 결정성·로컬 순위도 확인합니다. 브라우저 점검: 1단계 10박자, 30단계 19박자, 무한 시드 42 18박자에 UI 입력으로 입항했고 375px 너비에서 가로 넘침이 없었습니다. 실제 모바일 기기 현장 검증은 별도입니다.

## 파일

- `index.html` 화면 및 한글 도움말
- `style.css` 반응형 지도/UI
- `app.mjs` 브라우저 상호작용·피드백·소리·점수판
- `logic.mjs` 결정적 독립 게임 로직
- `game.test.mjs` Node 내장 테스트 (외부 의존성 없음)

제한: 온라인 순위·원격 동기화·실제 모바일 기기/스크린리더 현장 사용성 검증·외부 배포는 포함하지 않았습니다. 무한 모드는 고정 골격의 장식 변경이 아닌 시드별 항로 생성이지만 한 지도에는 하나의 설계된 안전 경로만 있습니다.
